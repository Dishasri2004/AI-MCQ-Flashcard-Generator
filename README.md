# 🚀 AI MCQ & Flashcard Generator

An AI-powered web application that converts PDF study materials into interactive MCQs and flashcards using NLP techniques.

---

## 🔥 Features

* 📄 Upload PDF study materials
* 🧠 Extract key concepts using NLP
* ❓ Generate MCQs automatically
* 🃏 Create flashcards for quick revision
* 📊 Performance tracking & analytics
* ⚡ Interactive UI with Streamlit

---

## 🛠 Tech Stack

* Python
* Streamlit
* Scikit-learn (TF-IDF, NLP)
* Pandas & NumPy
* Plotly (visualization)
* PyPDF (PDF extraction)

---

## 🚀 How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
